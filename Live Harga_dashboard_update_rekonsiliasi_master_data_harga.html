Pengaturan Cloud Database (Google Firebase)

Aplikasi ini tersambung ke **Google Firebase Cloud Firestore**. Masukkan konfigurasi JSON Firebase milik Anda sendiri agar data tersimpan penuh di akun Cloud proyek pribadi/perusahaan Anda:

Cara mendapatkan kunci Firebase gratis:

  1. Buka console.firebase.google.com & buat Proyek Baru.
  2. Tambahkan Web App & aktifkan Firestore Database.
  3. Salin `firebaseConfig` JSON ke dalam kotak di atas lalu simpan.
